# 七只小牛签约系统

## 项目简介

使用 AI 辅助编码开发的合同业务系统原型，用于验证业务、
法务和财务之间的合同申请、审批、模拟签署与归档流程。

当前为浏览器本地原型，不是生产系统。

## 运行方法

1. 下载项目，保留完整的 final_1025.html。
2. 使用 Chrome 或 Edge 打开 final_1025.html 进行基础体验。
3. 如果直接打开时出现存储、模块加载或签署窗口问题，
   请通过本地静态 HTTP 服务访问同一份文件。
4. PDF 正文提取需要联网加载 PDF.js。
5. 允许页面打开签署弹窗，并允许浏览器使用本地存储。

演示时请保持同一浏览器配置及同一访问地址。
不要混用本地文件地址和 HTTP 地址。

## 主要功能

- 标准模板填写、非标合同上传与正文提取。
- 主体信息规则识别、人工核对与回填。
- 非标合同紧急标记、主管分派与自行审批。
- 法务、财务审批，以及退回和修改附件。
- 合同版本记录、差异查看、消息与操作日志。
- 模拟签署、归档查询、扫描件导入和汇总导出。

## 推荐体验路径
业务创建标准合同 → 甲方签署 → 乙方签署 →查看合同汇总表

业务创建非标合同 → 主管分派 → 法务审批 →
财务审批 → 业务发起模拟签署 → 甲乙方签署 →
法务或财务查看合同汇总表。

## 使用限制

- 无后端，合同数据保存在 localStorage，附件保存在 IndexedDB。
- 不支持跨设备真实协同；清理站点数据可能导致记录和附件丢失。
- 登录、验证码、短信、印章均为演示机制，未接入真实签署服务。
- 信息识别采用本地规则，不是大模型识别；不内置 OCR。
- 文本提取不能保证还原原件排版，结果需要人工核对。
- 保密承诺函使用内置简化模板，尚未统一接入模板配置。
- 多窗口更新可能关闭正在编辑的弹窗。
- 当前签署完成返回内部账号的逻辑仅用于本地演示。
- 请勿输入真实敏感业务数据。
